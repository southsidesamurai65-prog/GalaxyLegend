银河传说 游戏
这是一款纯单机游戏，它的最核心玩法如下
对战双方都有3乘3的空间，可以在上面放置角色，最多放置5个
按照(x,y)坐标来描述，对垒双方大概长这样
(1,1) (1,2) (1,3)    (1,3) (1,2) (1,1)
(2,1) (2,2) (2,3)    (2,3) (2,2) (2,1)
(3,1) (3,2) (3,3)    (3,3) (3,2) (3,1)

角色的基本属性有两类，一类是绝对值属性，包括物理攻击，技能攻击，物理防御，技能防御，HP，初始蓄能(大部分角色为50)，速度。特殊职业毁灭者用能量攻击替代物理攻击。

另一类是百分比属性，包括命中，闪避，暴击，免爆，暴击伤害。

这个属性未来有可能推出更多，你要保证可扩充性。

总速度快的一方先行动，行动顺序为从前到后，从上到下，也就是(1,3)>(2,3)->(3,3)->(1,2)->(2,2)->...这个样子，然后是双方交替行动的。

角色的普通攻击优先攻击和自己同x(同行)且y最大(最靠前)的敌方，例如(2,2)的我方角色在(2,3)和(2,1)都有敌人时会攻击(2,3)，假如同行没有敌人，攻击顺序为上一行>下一行>上两行>下两行，总是先攻击靠前的y更大的，例如(2,2)在(1,1)和(3,3)有敌人时会攻击(1,1)

我们可以称这个普通攻击锁定的目标为靶点。普通攻击对靶点造成攻击方物理攻击-靶点物理防御的基础伤害(会受后续我要讲的一些机制的浮动)，毁灭者则是对靶点造成攻击者能量攻击的基础伤害(毁灭者无视物理防御，也会受机制影响)。当然以上是在命中的情况下，正常来说这次攻击会有攻击者命中-靶点闪避这么多命中率。暴击就是一个可以使伤害浮动的属性，正常来说攻击有攻击者暴击-靶点免爆这么多几率暴击，触发暴击则会造成暴击伤害倍率的伤害。

每个角色都有自己的技能，需要蓄能来释放，>=100蓄能会释放技能而不是用普通攻击(会有特殊机制改变这点，例如禁止释放技能)，释放后清空蓄能，技能的伤害根据释放时的蓄能决定，最终倍率 = 技能描述倍率 × 蓄能 / 100；例如150%技能在150蓄能时造成225%伤害。蓄能的获取主要是，普通攻击+25，挨打+25。

技能主要分为四种，单体攻击(攻击靶点)，纵向攻击(攻击靶点所在行)，横向攻击(攻击靶点所在列，也就是同y)，十字攻击(纵向+横向)，未来有可能扩充，保持可扩充性

技能的含义是这样的，例如单体攻击，造成150%伤害。100蓄能释放时，意思是对靶点造成1.5乘(攻击者物理(能量)攻击+技能攻击)-靶点物理防御-靶点技能防御的基础伤害；实际倍率 = 技能描述倍率 × 蓄能 / 100。毁灭者依然是无视物理防御。

技能也要经过命中和暴击判定。

然后一些机制，也要维持可扩充
锁定，目标无法行动。
护盾，一般有行动次数限制，相当于临时HP。
神圣伤害，无视防御，包括物理防御和技能防御。

还有一个叫氪晶的东西，类似装备，可以提升角色的属性，但是格子有限，得自己考虑用哪些。你可以先初步弄一个框架。

## 实现约定

以下细节用于统一实现，后续如有冲突以本节为准。

1. **行动交替**：总速度快的一方先手；之后双方按各自的行动顺序交替，即“快方1号 → 慢方1号 → 快方2号 → …”。一方先行动完，另一方剩余单位继续依次行动；死亡单位轮到时跳过，不改变交替节奏。
2. **总速度**：只在开局用双方全部单位的速度之和判定一次，之后每回合沿用；相同则我方先手。
3. **行动顺序**：每方内部按 y 从大到小（前排先）、同 y 按 x 从小到大（上到下）。
4. **持续时间**：所有持续效果按“受影响单位自身的行动次数”计算，在该单位行动结束时 -1；被锁定跳过也计一次；效果在施加当次行动不计数；减到 0 移除。
5. **蓄能**：初始蓄能由属性决定；普攻或技能未命中不加；同一次行动中攻击方最多 +25，多目标不重复；每个受击单位每次行动最多 +25；技能释放时先清空蓄能，若命中再按上述规则 +25；上限 300。
6. **技能倍率**：最终倍率 = 技能描述倍率 × 蓄能 / 100。100 蓄能 = 1.0 倍描述伤害，150 蓄能 = 1.5 倍，300 蓄能 = 3.0 倍。多目标技能对每个目标分别判定命中/暴击。
7. **伤害顺序**：先算基础伤害（普攻/技能、毁灭者、神圣），再判命中，再判暴击并乘暴击伤害倍率，最后向下取整，最低 1 点；护盾在 HP 之前吸收。
8. **命中/暴击率**：命中率 = 命中 - 闪避，暴击率 = 暴击 - 免爆，均限制在 0%～100%。
9. **毁灭者**：普攻和技能都用能量攻击替代物理攻击，并忽略物理防御；技能仍然吃技能防御（神圣伤害除外）。
10. **神圣伤害**：只无视物理防御和技能防御；命中、暴击、护盾都照常生效。
11. **护盾**：多层独立叠加，各自计时；伤害按施加顺序依次吸收；被完全吸收的命中仍算“挨打”，正常 +25；护盾可超过当前 HP。
12. **锁定**：目标跳过行动；跳过的那次行动仍会递减其身上的持续时间；锁定本身也按行动次数计时。
13. **禁技**：不能释放技能，改为普攻并正常获得 +25；蓄能保留，禁技结束后若 >=100 立即释放技能；禁技同样按行动次数计时。
14. **技能效果**：技能可配置“自身效果”（例如护盾，释放时施加）和“命中后效果”（例如锁定/禁技）；当前技能均为敌方目标，后续可扩展友方/自身目标。
15. **氪晶**：每个角色独立槽位（暂定 3 格）；全队共享库存、不可重复装备、战间可自由更换；氪晶可影响所有已注册属性，包括速度和初始蓄能。

## 运行与测试

```bash
npm install
npm run dev       # 本地开发
npm test          # 机制回归测试
npm run build     # 类型检查 + 生产构建
```

`scripts/simulate.ts` 可以无界面跑一场完整战斗并打印日志；`scripts/balance.ts` 可以批量模拟胜率。
