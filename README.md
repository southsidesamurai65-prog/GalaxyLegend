银河传说 游戏
这是一款纯单机游戏，它的最核心玩法如下
对战双方都有3乘3的空间，可以在上面放置角色，最多放置5个
按照(x,y)坐标来描述，对垒双方大概长这样
(1,1) (1,2) (1,3)    (1,3) (1,2) (1,1)
(2,1) (2,2) (2,3)    (2,3) (2,2) (2,1)
(3,1) (3,2) (3,3)    (3,3) (3,2) (3,1)

角色的基本属性有两类，一类是绝对值属性，包括物理攻击，技能攻击，物理防御，技能防御，HP，初始蓄能(大部分角色为50)，速度。特殊职业毁灭者用能量攻击替代物理攻击。

另一类是百分比属性，包括命中，闪避，暴击，免爆，暴击伤害，拦截，破防。
[New!26/11/12]新增属性拦截，破防，受到攻击时有"攻击者破防-自身拦截"这么高几率触发拦截，降低50%受到的伤害，如果拦截的是普通攻击，则还会以普通攻击的形式还击攻击者，并且获得25蓄能。

这个属性未来有可能推出更多，你要保证可扩充性。

总速度快的一方先行动，行动顺序为从前到后，从上到下，也就是(1,3)>(2,3)->(3,3)->(1,2)->(2,2)->...这个样子，然后是双方交替行动的。

角色的普通攻击优先攻击和自己同x(同行)且y最大(最靠前)的敌方，例如(2,2)的我方角色在(2,3)和(2,1)都有敌人时会攻击(2,3)，假如同行没有敌人，攻击顺序为上一行>下一行>上两行>下两行，总是先攻击靠前的y更大的，例如(2,2)在(1,1)和(3,3)有敌人时会攻击(1,1)

我们可以称这个普通攻击锁定的目标为靶点。普通攻击对靶点造成攻击方物理攻击-靶点物理防御的基础伤害(会受后续我要讲的一些机制的浮动)，毁灭者则是对靶点造成攻击者能量攻击的基础伤害(毁灭者无视物理防御，也会受机制影响)。当然以上是在命中的情况下，正常来说这次攻击会有攻击者命中-靶点闪避这么多命中率。暴击就是一个可以使伤害浮动的属性，正常来说攻击有攻击者暴击-靶点免爆这么多几率暴击，触发暴击则会造成暴击伤害倍率的伤害。

每个角色都有自己的技能，需要蓄能来释放，>=100蓄能会释放技能而不是用普通攻击(会有特殊机制改变这点，例如禁止释放技能)，释放后清空蓄能，技能的伤害根据释放时的蓄能决定，最终倍率 = 技能描述倍率 × 蓄能 / 100；例如150%技能在150蓄能时造成225%伤害。蓄能的获取主要是，普通攻击+25，挨打+25。

技能主要分为四种，单体攻击(攻击靶点)，纵向攻击(攻击靶点所在行)，横向攻击(攻击靶点所在列，也就是同y)，十字攻击(纵向+横向)，未来有可能扩充，保持可扩充性

技能的含义是这样的，例如单体攻击，造成150%伤害。100蓄能释放时，意思是对靶点造成1.5乘(攻击者物理(能量)攻击+技能攻击)-靶点物理防御-靶点技能防御的基础伤害；实际倍率 = 技能描述倍率 × 蓄能 / 100。毁灭者无视物理防御和技能防御，只受能量防御抵挡。

技能也要经过命中和暴击判定。

然后一些机制，也要维持可扩充
锁定，目标无法行动。
护盾，一般有行动次数限制，相当于临时HP。
神圣伤害，无视防御，包括物理防御和技能防御。

还有一个叫氪晶的东西，类似装备，可以提升角色的属性，但是格子有限，得自己考虑用哪些。你可以先初步弄一个框架。

## 实现约定

以下细节用于统一实现，后续如有冲突以本节为准。

1. **行动交替**：总速度快的一方先手；之后双方按各自的行动顺序交替，即“快方1号 → 慢方1号 → 快方2号 → …”。一方先行动完，另一方剩余单位继续依次行动；死亡单位轮到时跳过，不改变交替节奏。
2. **总速度**：只在开局用双方全部单位的速度之和判定一次，之后每回合沿用；相同则我方先手。
3. **行动顺序**：每方内部按 y 从大到小（前排先）、同 y 按 x 从小到大（上到下）。
4. **持续时间**：所有持续效果按“受影响单位自身的行动次数”计算，并在该单位每次行动开始前结算。x 回合效果会在第 x+1 次行动开始前移除，因此第 x 次行动以及其间的其他单位行动都仍然生效；被锁定跳过也计一次；效果在施加当次行动不计数。
5. **蓄能**：初始蓄能由属性决定；普攻未命中不加；普攻命中时攻击方 +25；每个受击单位每次行动最多 +25，多目标不重复；技能默认先清空蓄能，本次释放不会给攻击方额外 +25；特殊技能可配置只消耗一部分（例如氢弹消耗一半）；上限 300。
6. **技能倍率**：最终倍率 = 技能描述倍率 × 蓄能 / 100。100 蓄能 = 1.0 倍描述伤害，150 蓄能 = 1.5 倍，300 蓄能 = 3.0 倍。多目标技能对每个目标分别判定命中/暴击。
7. **伤害顺序**：先算基础伤害（普攻/技能、毁灭者、神圣），再判命中，再判暴击并乘暴击伤害倍率，最后向下取整，最低 1 点；护盾在 HP 之前吸收。
8. **命中/暴击率**：命中率 = 命中 - 闪避，暴击率 = 暴击 - 免爆，均限制在 0%～100%。
9. **毁灭者**：普攻和技能都用能量攻击替代物理攻击，并忽略物理防御和技能防御；只会被“能量防御”抵挡。
10. **神圣伤害**：无视物理防御、技能防御和能量防御；命中、暴击、护盾都照常生效。
11. **护盾**：多层独立叠加，各自计时；伤害按施加顺序依次吸收；被完全吸收的命中仍算“挨打”，正常 +25；护盾可超过当前 HP。
12. **锁定**：目标跳过行动；跳过的那次行动仍会递减其身上的持续时间；锁定本身也按行动次数计时。
13. **禁技**：不能释放技能，改为普攻并正常获得 +25；蓄能保留，禁技结束后若 >=100 立即释放技能；禁技同样按行动次数计时。
14. **技能效果**：技能可配置自身效果、全体友方效果、随机队友效果，以及命中后对目标施加的效果（减益/锁定/禁技等）。纯增益技能可以没有伤害，也不会占用敌方靶点。
15. **氪晶**：每个角色独立槽位（暂定 3 格）；全队共享库存、不可重复装备、战间可自由更换；氪晶可影响所有已注册属性，包括速度和初始蓄能。氪晶定义从 `kejing.txt` 解析，R5 氪晶默认按 7 级计算（`基础值 + 每级成长 × 6`），R4 按固定值。
16. **拦截/破防**：受到攻击时按“攻击者破防 - 自身拦截”判定拦截，触发率限制在 0%～100%；触发后本次伤害降低 50%。若拦截的是普通攻击，还会立即以普通攻击还击攻击者，并获得 25 蓄能。

## 角色数据（codex.txt）

角色图鉴直接从 `codex.txt` 解析，修改后 Vite 会热更新，不需要手动改 TypeScript 数据。

- 阵营与稀有度：按 `阵营(数量)` 和 `名字(稀有度)，技能：...` 解析。
- 属性顺序：`HP 物理攻击 物理防御 技能攻击 技能防御 [能量攻击] 暴击 免爆 暴击伤害 拦截 破防 闪避 命中 速度 初始蓄能`。
- 能量攻击只有毁灭者填写；其他职业的属性行会跳过这一位。
- 非毁灭者写 14 位属性，毁灭者写 15 位；毁灭者的物理攻击位写“无”表示 0。仍兼容旧版 12/13 位写法。
- 没有属性行的角色会显示“数据待补”，不能上阵；补上属性后自动可用。
- 旗舰角色必须上阵且只能上阵 1 艘。
- 同名技能如果效果完全相同会共享；如果同名但效果不同，会自动为该角色生成独立变体。

技能描述目前支持这些关键词：

- 形状：`单体`、`横向`/`同列`、`纵向`/`同行`、`十字`、`自身`/`全体`（无伤害增益）。
- 伤害：`X%伤害`，或单独一段 `X%`。
- 减益：`降低目标X%物理攻击N回合`、`降低目标X%物理防御N回合`、`降低目标X%技能防御N回合`。
- 控制：`锁定目标N回合`、`X%锁定目标N回合`（按每个目标单独判定）、`禁技N回合`、`X%几率冰冻目标N回合`（冰冻 = 锁定 + 物理防御 -20%）。
- 隐身：`使血量最少的队友(包括自身)隐身N回合`、`将被攻击的目标隐身N回合`；隐身单位不会被选为靶点或攻击到。
- 特殊：`清空目标蓄能`、`减少目标X蓄能`（若同时写“不加还倒扣”，本次挨打也不加蓄能）、`仅消耗一半蓄能`、`额外附带X神圣伤害`、`增加自身X蓄能`、`增加全体X蓄能`、`本次攻击不会增加目标蓄能`。
- 中毒：`使目标进入中毒，每回合损失X%技能伤害的HP，持续N回合`。
- 增益：`增加/提高/提升` + `自身/全体/随机一名队友` + `X%属性N回合`；支持“暴击和命中”这类多属性写法。
- 防御：`能量防御` 是独立属性，专门抵挡毁灭者的能量攻击；当前通过 `增加自身X能量防御N回合` 这类描述施加。
- 神圣：描述里出现“神圣”或“无视防御”；“额外附带X神圣伤害”会作为独立加伤，不会把主伤害整体变成神圣。

无法识别的描述会退化成“有形状/倍率的伤害技能”；新的特殊机制需要在代码里补充解析和结算。

默认玩家阵容和默认氪晶搭配在 `src/game/Game.ts` 里；氪晶种类与数值在 `kejing.txt` 里，修改后 Vite 会热更新。敌方阵容从全部完整角色中随机抽取 5 名（最多 1 艘旗舰），每次重置、返回准备阶段或点击“刷新敌人”都会重新随机位置与氪晶。

## 等级与装备

- codex 里的属性是 1 级状态；游戏默认按 75 级战斗。
- 75 级时 HP、物理攻击、物理防御、技能攻击、技能防御、能量攻击 = 1 级 × 15；百分比属性与初始蓄能不变。
- 速度走单独的每级成长：旗舰/护卫 +2/级，突击 +3/级，打击 +4/级，徘徊/毁灭 +5/级；从 1 级到 75 级共成长 74 次。
- 75 级固定装备加成（打架时直接叠加，不单独做成装备栏）：HP +66400，物理攻击 +46500，物理防御/技能攻击/技能防御 +33200，能量攻击 +19900，速度 +2612。
- 氪晶在“1 级基础 ×15 + 等级装备”之后按百分比/固定值叠加。

## 视觉反馈

- 准备阶段：点击“自定义敌方”后，可以选择角色并点击敌方格子放置、替换或移动敌人，也支持移除选中、清空和随机敌方；点击敌方角色还能编辑其氪晶，敌方氪晶与玩家氪晶互相独立。战斗阶段顶部固定显示当前回合数。
- 阵容存档：准备阶段底部可以给当前双方阵容命名并保存（包含角色位置和双方氪晶），存档保存在浏览器 localStorage，可随时读取或删除。
- 背景：固定银河层，包含星云、闪烁星星和周期性划过的流星；系统开启“减少动态效果”时会自动关闭闪烁和流星。
- 战场：双方 3×3 阵列共用一个斜向透视平面，我方在左下、敌方在右上；战斗阶段隐藏格子边框，只显示悬浮舰船、分段 HP/蓄能和状态特效。
- 普攻：从攻击者飞向靶点的弹道球，命中后出现冲击环和伤害数字。
- 技能：从施法者射向每个目标的技能光束，同时高亮完整技能范围；自身/友方增益会显示绿色光环，护盾显示蓝色光环。
- 暴击为金色、神圣为紫色、闪避显示 MISS；护盾吸收、蓄能增减、锁定/禁技/冰冻、隐身、中毒、额外神圣伤害、拦截、阵亡都有对应飘字和徽章。
- 阵亡：在对应格子播放爆炸特效（闪光、火球、冲击波、飞散碎片和烟雾），并让战场短暂震动；系统开启“减少动态效果”时会自动省略碎片、烟雾和震动。
- 属性提升：命中提高显示青色风环，暴击提高显示粉紫爆裂和星屑，拦截提高显示紫色六边形护罩；这些效果会持续到对应增益结束。
- 伤害数字在弹道命中后再出现；弹道和飘字放在独立覆盖层里，不会被棋盘重绘截断。

## 手机版

- 页面在 820px 以下自动切换到手机布局：双方棋盘缩放后并排显示，按钮和触控区域放大，底部操作栏固定，方便单手开战。
- 手机浏览器打开后可以“添加到主屏幕”，像普通 App 一样全屏启动；已包含 manifest、应用图标和离线缓存。
- 战斗中点击棋盘角色，详情会自动滚动到可视区域。

让完全不懂电脑的人玩，最省事的方式是给一个网址：

1. 把游戏发布到公网（任选一种）：
   - **GitHub Pages**：仓库已带 `.github/workflows/deploy.yml`。推到 GitHub 后，在仓库 `Settings → Pages → Build and deployment` 选择 `GitHub Actions`，之后每次推送都会自动更新。
   - **Netlify Drop**：本机执行 `npm run build`，把 `dist` 文件夹直接拖到 <https://app.netlify.com/drop>，会得到一个可直接分享的网址。
   - **Vercel / Cloudflare Pages**：构建命令 `npm run build`，输出目录 `dist`。
2. 把网址发给对方（微信、短信都可以）。
3. 对方在手机上打开：
   - iPhone / Safari：点底部“分享” → “添加到主屏幕”。
   - Android / Chrome：点右上角菜单 → “安装应用”或“添加到主屏幕”。
4. 以后直接点桌面图标进入，不需要安装 Node，也不需要开电脑。

同一 WiFi 下想先用自己的手机试玩，可以运行：

```bash
npm run dev -- --host
```

然后用手机访问终端里显示的 `Network` 地址（例如 `http://192.168.1.20:5173`）。这只是测试用，电脑关掉就打不开了。

## 运行与测试

```bash
npm install
npm run dev       # 本地开发
npm test          # 机制回归测试
npm run build     # 类型检查 + 生产构建
```
